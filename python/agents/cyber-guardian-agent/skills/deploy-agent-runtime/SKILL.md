# Deploying Cyber Guardian Agent to Vertex AI Agent Runtime

> [!NOTE]
> This skill guide was generated by the **Antigravity/Jetski** coding agent in July 2026.
> Before executing this workflow for the first time locally, it is advised to check the GitHub repository for the latest version and updates.

This guide outlines the end-to-end workflow to fetch the cyber-guardian-agent source code, deploy it to the managed **Agent Runtime (Vertex AI Reasoning Engine)** on Google Cloud, and run validation tests.

---

## Prerequisites

Ensure you have the following CLI utilities installed:
- [gcloud CLI](https://cloud.google.com/sdk/docs/install)
- [uv](https://docs.astral.sh/uv/getting-started/installation/)
- `agents-cli` (Install using: `uv tool install google-agents-cli` then `agents-cli update`)

---

## Step 1: Sync Code and skills from GitHub

Clone the repository containing the agent samples and navigate to the agent directory:

```bash
# Clone the repository
git clone https://github.com/davxiao/adk-samples.git

# Navigate to the cyber-guardian agent directory
cd adk-samples/python/agents/cyber-guardian-agent
```

Initialize the Python virtual environment and download dependencies:

```bash
# Install the agents-cli tool globally (one-time setup)
uv tool install google-agents-cli

# Install dependencies and sync virtualenv
uv sync
```

---

## Step 2: Configure GCP Authentication & Project

Authenticate your shell to GCP and configure your target project:

```bash
# Authenticate gcloud CLI
gcloud auth login

# Set application default credentials for client libraries
gcloud auth application-default login

# Configure target project
gcloud config set project YOUR_PROJECT_ID
```

Ensure the necessary APIs are enabled in your target project:
```bash
gcloud services enable \
  aiplatform.googleapis.com \
  cloudbuild.googleapis.com \
  run.googleapis.com \
  bigquery.googleapis.com
```

---

## Step 3: Deploy to Agent Runtime

1. Verify `agents-cli-manifest.yaml` is configured with `deployment_target: agent_runtime`:
   ```yaml
   acli_version: 1.0.0
   name: cyber-guardian
   agent_directory: cyber_guardian
   create_params:
     deployment_target: agent_runtime
   ```

2. Run the deployment command:
   ```bash
   agents-cli deploy --project YOUR_PROJECT_ID --region us-central1
   ```

3. **Handling timeouts**: Agent Runtime deployments take 5 to 10 minutes because the platform builds a container image under the hood. If the CLI command times out or is interrupted, the deployment continues server-side. Check the status by running:
   ```bash
   agents-cli deploy --status
   ```
   Once successful, this updates the `deployment_metadata.json` with the deployed resource ID.

---

## Step 4: Verify Deployment with a Quick Test

Query your deployed agent using `agents-cli run`. The tool automatically handles authentication and session state:

```bash
# Run a quick test using the default example question
agents-cli run --mode adk "Run triage for hostname kvm01 and alert IOC_MATCH"
```

*Note: The CLI reads the engine resource ID from `deployment_metadata.json`. To target a specific URL or engine resource ID explicitly:*

```bash
agents-cli run \
  --url https://us-central1-aiplatform.googleapis.com/v1/projects/YOUR_PROJECT_ID/locations/us-central1/reasoningEngines/YOUR_ENGINE_ID \
  --mode adk \
  "Run triage for hostname kvm01 and alert IOC_MATCH"
```
